# Feedback & Issue Guidelines

**Slant** is under active development — bug reports, feature suggestions, and new architectural window frame ideas are all very welcome via **Issues**.

本项目持续维护与更新，欢迎通过 **Issues** 反馈 Bug、提出改进建议或分享新窗框/光影创意。

## How to Share Feedback

- **Report bugs**: Open a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) with your Windows version, display scaling, and steps to reproduce.
- **Suggest ideas**: Open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) for new window mullion styles, lighting/weather nuances, or UX improvements.

## Pull Requests Policy

This repository does not currently accept external Pull Requests. If you would like to customize Slant for your own setup, feel free to fork the repository under the terms of the [GPL-3.0 License](LICENSE).

本项目暂不接受外部 Pull Request；如需个性化修改，欢迎在遵循 [GPL-3.0 协议](LICENSE) 的前提下自行 Fork。
