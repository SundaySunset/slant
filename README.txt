============================================================
  寸度 · Slant  (Windows 10 / 11 原生桌面与锁屏版)
============================================================

【使用前请先完整解压本压缩包到任意固定文件夹（如 D:\Cundu）】

一、原生 Windows 桌面壁纸与系统锁屏程序
------------------------------------------------------------
1. 双击运行 ObliqueSeasons.exe（或 Start-Oblique-Seasons.bat）
   - 启动现代深色标题栏控制与预览窗口，可先在窗口内挑选 10 款窗格样式并调节
     光影、天气与景物，再通过底栏或「系统」页一键点击「设为桌面壁纸」或
     「设为系统锁屏」（仅静默后台/开机自启时会按上次设置自动挂载动态桌面）。
   - 兼容 Windows 10、Windows 11 23H2 及 Windows 11 24H2 / 25H2+ 新版桌面架构，
     可将实时 WebGL 窗影嵌入桌面图标底层。

2. 系统桌面壁纸模式（托盘右键或面板「系统 -> 壁纸与锁屏」切换）：
   - 动态壁纸：在桌面图标底层实时渲染四季风影与实况天气，自动备份原有桌面
     壁纸并支持一键恢复；全屏游戏或视频时可自动暂停动态渲染以节省 GPU。
   - 静态壁纸：按主显示器原生物理分辨率渲染高清画面，写入 Windows 桌面背景。
   - 关闭：关闭动态桌面覆盖并保留后台控制与锁屏同步。

3. Windows 系统锁屏（无需管理员权限）：
   - 一键「设为系统锁屏」：按主显示器原生物理分辨率截取当前画面并通过
     Windows 原生 WinRT 接口设为系统锁屏。
   - 支持「锁屏定时自动同步」（可选 15 / 30 / 60 分钟，并在系统唤醒或解锁时
     自动刷新），让锁屏画面随时间与天气自然演变。
   - 注意：若系统个性化中开启了「Windows 聚焦」，部分系统策略可能会覆盖图片锁屏，
     可在「系统 -> 工具与恢复」中点击打开 Windows 锁屏设置并将背景切换为「图片」。

4. 界面与语言：
   - 控制面板共 4 个标签页：光影、天气、景物、系统；底栏为「设为桌面壁纸」与
     「设为系统锁屏」。
   - 界面语言可在「系统 -> 常规偏好」中切换（自动 / 中文「寸度」 / EN「Slant」）。

5. 命令行启动参数：
   - ObliqueSeasons.exe              打开控制与预览窗口
   - ObliqueSeasons.exe --window     以独立窗口模式打开（不强制挂载动态桌面）
   - ObliqueSeasons.exe --desktop    静默启动至系统托盘并按设置运行动态壁纸
   - ObliqueSeasons.exe --autostart  开机自启静默托盘模式

二、独立窗口 / 全屏预览模式
------------------------------------------------------------
- 双击 Start-Window-Mode.bat，以独立窗口打开，按 F 进入全屏，按 H 展开参数面板。

三、网络与隐私说明
------------------------------------------------------------
- 仅在开启「实况天气」时向 Open-Meteo 及公共 IP 定位接口请求天气/地理坐标；
  程序不包含任何遥测、统计上报或账号上传逻辑，所有偏好设置均保存在本机。

四、自行编译（可选）
------------------------------------------------------------
- 如修改了 src/ 目录源码，可双击运行 Build-EXE.bat（需安装 .NET 8 SDK），
  将重新编译发布单文件版 ObliqueSeasons.exe。

五、兼容 Wallpaper Engine / Lively Wallpaper
------------------------------------------------------------
- Wallpaper Engine：创意工坊/编辑器 -> 打开本地壁纸 -> 选择本目录中的 project.json。
- Lively Wallpaper：直接将解压后的文件夹拖入 Lively 主界面即可识别。

系统要求：
- Windows 10 (19041+) / Windows 11
- .NET 8 Desktop Runtime (x64)
- Microsoft Edge WebView2 Runtime（Windows 11 及新版 Windows 10 已内置）
